# Skivback FM v3.3

Statisk GitHub Pages-app med dold YouTube IFrame-spelare.

## Nytt i v3.3

- Blue Ark är vald vid start.
- Station 18–23 följer ordningen Kult FM, Still Slipping Los Santos, The Music Locker, Media Player, Motomami Los Santos och Blonded Los Santos.
- Endast en Media Player finns i listan.
- Alla logotyper laddas lokalt från `assets/logos/`.
- Landscape använder en smal scrollbar ikonlist och låter Now Playing-panelen fylla resten av skärmen.
- Ikonerna i landscape är så stora som möjligt utan att tränga undan spelaren.

Ladda upp hela innehållet till roten av GitHub-repot.
