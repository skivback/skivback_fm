# Skivback FM v4 preview

Denna preview använder de 15 stationslogotyper som hittills laddats upp, lokalt i `assets/logos/`.
Återstående stationer använder tillfälligt tidigare SVG-logotyper tills de riktiga bilderna har laddats upp.

Landscape-läget har förenklats:
- endast logotyper i vänsterlisten
- ingen extra stationslogga eller frekvens i spelarens övre hörn
- Now Playing fyller resten av skärmen
- Blue Ark är standardstation
